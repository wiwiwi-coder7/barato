# طراحی: تولد عمومی و امنیت پنل Barato

## محدودهٔ تأییدشده

تجربهٔ تولد عمومی به‌صورت یک حالت تازه در همان جریان ساخت لینک اضافه می‌شود و مسیر مستقل تولد آدین را تغییر نمی‌دهد. هر لینک تولد با همان نشانی عمومی هدیه باز می‌شود، اما براساس نوع تجربه به صحنهٔ شمع و کیک هدایت خواهد شد. کاربر هنگام ساخت، نام، پیام، سن، کیک و شیوهٔ شمع را انتخاب می‌کند. عکس سفارشی کیک فقط پس از بازکردن قابلیت تصویر مجاز است.

| مورد | تصمیم اجرایی |
|---|---|
| مدل داده | جدول فعلی `gifts` با نوع تجربه و تنظیمات تولد توسعه می‌یابد تا آمار، تاریخ انقضا، مدیریت لینک و رخدادهای فنی موجود بدون تکثیر حفظ شوند. |
| کیک‌های آماده | جدول مستقل `birthday_cake_presets` شامل کلید ذخیره‌سازی، برچسب، ترتیب و نشان «دارای شمع داخلی» ایجاد می‌شود. |
| سن و شمع | سن ۰ تا ۹ یک رقم و سن ۱۰ تا ۹۹ دو رقم را نمایش می‌دهد. کیکِ دارای شمع داخلی، شمع عددی اضافه نمی‌گیرد. |
| فوت | با تحلیل سطح صدای میکروفون، شعله‌ها خاموش می‌شوند. دکمهٔ جایگزین برای رد مجوز میکروفون یا دستگاه‌های ناسازگار در دسترس می‌ماند. |
| جلوهٔ شمع | انیمیشن بومی CSS برای شعلهٔ شماره‌ها استفاده می‌شود تا تعامل روشن/خاموش قابل‌اعتماد باشد. یک انیمیشن CC0 از Wikimedia Commons نیز به‌عنوان دارایی پژوهش‌شده و فشرده‌شده نگهداری می‌شود؛ انتخاب نهایی رابط فقط دارایی‌های سبک و مناسب پس‌زمینهٔ شفاف را نمایش می‌دهد. |
| رمز مدیر | درخواست تغییر رمز، رمز فعلی و تکرار رمز جدید را بررسی می‌کند؛ hash جدید با salt تازه ذخیره می‌شود و همهٔ نشست‌های مدیریتی پیشین لغو می‌گردند. |
| قفل تصویر | رمز مدیر و رمز اختصاصی تصویر هر دو قابلیت تصویر را باز می‌کنند تا مالک با مشخصات شناخته‌شدهٔ خود به خطای اعتبارسنجی نرسد. |

## رفتار و خطا

اگر مجوز میکروفون داده نشود یا صدای ورودی قابل‌استفاده نباشد، صفحه بدون اختلال می‌ماند و دکمهٔ «خاموش‌کردن شمع» جایگزین عمل فوت می‌شود. تصویر نامعتبر یا بیش از اندازه پیش از بارگذاری رد می‌شود. تصویرهای آماده به‌صورت کلیدهای ذخیره‌سازی عمومی نگهداری خواهند شد و تصویر سفارشی از همان مسیر قفل‌شدهٔ فعلی استفاده می‌کند.

## آزمون و انتشار

آزمون‌های واحد برای تبدیل سن به رقم‌ها، منطق حذف شمع عددی برای کیک‌های دارای شمع، آستانهٔ فوت و اعتبارسنجی تغییر رمز افزوده می‌شوند. سپس migration، Edge Function و فرانت‌اند هم‌زمان منتشر شده و جریان ساخت، فوت یا دکمهٔ جایگزین، بازشدن لینک و تغییر رمز در نسخهٔ زنده بررسی می‌شود.

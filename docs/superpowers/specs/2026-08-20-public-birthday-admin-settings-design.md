# طراحی عمومی‌سازی تولد و تنظیمات پنل مدیر Barato

## هدف

تجربهٔ تولدِ آزمون‌شده برای کاربران عادی در فرم ساخت لینک فعال می‌شود. مدیر می‌تواند بدون ویرایش کد، وضعیت عرضه، متن راهنمای شمع، رنگ پس‌زمینه و مجموعهٔ کیک‌های قابل انتخاب را کنترل کند. پنل مدیر نیز با بخش‌های روشن و مستقل برای نمای کلی، لینک‌ها، تولد عمومی و امنیت سازمان‌دهی می‌شود. مسیر تولد اختصاصی آدین تغییر نمی‌کند.

## ساختار رابط مدیر

پنل مدیر چهار بخش دارد. نمای کلی، آمار فعلی و میانبرهای اصلی را نشان می‌دهد. بخش لینک‌ها، فهرست، ویرایش، حذف و جزئیات فنی رخدادهای هر لینک را نگه می‌دارد. بخش تولد عمومی شامل کنترل عرضه، پیش‌نمایش تنظیمات، متن راهنما، رنگ پس‌زمینه و گالری کیک‌ها است. بخش امنیت، تغییر رمز مدیریت را در خود نگه می‌دارد. محتوای اختصاصی آدین در بخش تولد اختصاصی باقی می‌ماند و با تنظیمات تولد عمومی ترکیب نمی‌شود.

## مدل داده و قرارداد API

یک جدول singleton به نام `birthday_public_settings` برای تنظیمات عمومی افزوده می‌شود. این جدول شامل `is_enabled`، `candle_prompt`، `background_color` و زمان به‌روزرسانی است. مقدار پیش‌فرض متن، «آرزو کن و شمع را فوت کن» و رنگ پیش‌فرض همان زمینهٔ بنفش فعلی تجربه است. تنها یک ردیف با کلید ثابت `public` وجود دارد.

جدول موجود `birthday_cake_presets` مرجع کیک‌های آماده می‌ماند. عملیات مدیر به‌صورت افزایشی به قرارداد API اضافه می‌شوند: دریافت/به‌روزرسانی تنظیمات، فهرست کامل کیک‌ها، افزودن کیک با تصویر بارگذاری‌شده، ویرایش برچسب/ترتیب/وضعیت شمع داخلی/وضعیت نمایش عمومی و حذف کیک. API عمومی فقط تنظیمات لازم برای رندر و کیک‌های فعال را برمی‌گرداند.

در `create-gift`، لینک معمولی بدون تغییر ساخته می‌شود. درخواست با `experience: birthday` فقط هنگامی پذیرفته می‌شود که `birthday_public_settings.is_enabled` درست باشد. این کنترل سمت سرور انجام می‌شود تا مخفی‌کردن رابط به‌تنهایی راه دورزدن نباشد.

## جریان تجربه و تصویر

کاربر در فرم ساخت لینک، نوع «هدیه» یا «تولد» را انتخاب می‌کند. در حالت تولد، سن، کیک و در صورت مجازبودن تصویر سفارشی انتخاب می‌شود. شمع مستقلِ آماده ابتدا نمایش داده می‌شود؛ با فوت یا دکمهٔ جایگزین خاموش می‌شود و سپس کیک و پیام ظاهر می‌گردند. متن بالای شمع و رنگ زمینه از تنظیمات عمومی خوانده می‌شوند. کیک‌های دارای شمع داخلی همچنان شمع عددی اضافه نمی‌گیرند.

بارگذاری تصویر از مسیر موجود `upload-image` استفاده می‌کند. کنترل MIME، اندازه و نشست رمز تصویر بدون تغییر باقی می‌ماند. در پنل مدیر، همان مسیر برای بارگذاری یا جایگزینی تصاویر کیک استفاده می‌شود و خطاهای سرویس با پیام فارسی نمایش داده می‌شوند.

## اعتبارسنجی و آزمون

مرز API همهٔ ورودی‌های تنظیمات را اعتبارسنجی می‌کند: متن راهنما حداکثر ۱۲۰ نویسه، رنگ با الگوی hex شش‌رقمی، برچسب کیک حداکثر ۱۰۰ نویسه و ترتیب در بازهٔ قابل قبول. فقط مدیر به APIهای مدیریتی دسترسی دارد. حذف preset، لینک‌های قدیمی را تغییر نمی‌دهد؛ هر لینک کلید تصویر انتخاب‌شده را نزد خود نگه می‌دارد.

آزمون‌ها شامل گیت سمت سرور برای فعال/غیرفعال بودن تولد، اعتبارسنجی تنظیمات، تبدیل preset به مدل کلاینت، رندر متن و رنگ سفارشی در تجربه و مسیر بارگذاری تصویر هستند. پس از انتشار، یک لینک تولد عمومی و یک تصویر آزمایشی ساخته می‌شود؛ رندر، خاموش‌کردن شمع، نمایش کیک و دسترسی به تصویر بررسی و سپس دادهٔ آزمایشی حذف می‌شود.

## مرز عرضه

پس از انتشار این طرح، وضعیت تولد عمومی روی «فعال» تنظیم می‌شود؛ مدیر در هر زمان می‌تواند آن را غیرفعال کند. غیرفعال‌کردن فقط ساخت لینک‌های جدید تولد را می‌بندد و لینک‌های تولد ساخته‌شده را حذف یا از کار نمی‌اندازد.

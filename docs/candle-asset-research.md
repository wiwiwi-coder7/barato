# بررسی دارایی شمع برای تولد عمومی

- دارایی «Free Candle Flame Animation» از LottieFiles با مجوز Lottie Simple License، فرمت‌های JSON و GIF سبک ارائه می‌کند.
- دریافت مستقیم فایل از صفحهٔ مورد بررسی، ایجاد حساب کاربری را الزامی کرد؛ بنابراین برای جلوگیری از وابستگی به حساب شخصی یا دارایی غیرقابل‌بازنشر، این گزینه در نسخهٔ پروژه استفاده نمی‌شود.
- گزینهٔ بعدی باید دارایی با دریافت عمومی و مجوز صریح باشد؛ در غیر این صورت، شعلهٔ روشن/خاموش با انیمیشن بومی CSS پیاده‌سازی می‌شود تا پروژه مستقل بماند.

## گزینهٔ انتخاب‌شده

صفحهٔ Wikimedia Commons برای [Candle flame closeup animation.gif](https://commons.wikimedia.org/wiki/File:Candle_flame_closeup_animation.gif) استفادهٔ تجاری، تغییر و بازتوزیع را با مجوز CC0 1.0 مجاز می‌داند. این دارایی برای شعلهٔ تزئینی انتخاب شده است. ذخیرهٔ مستقیم از نما با پاسخ نامعتبرِ فایل مواجه شد؛ بنابراین دریافت از نشانی اصلی فایل از مسیر جایگزین انجام می‌شود.

برای نسخهٔ آزمون جدید، شمع CSS جای خود را به [Free Candle Flame Animation by Xandercorp](https://lottiefiles.com/free-animation/candle-flame-FTvxzGSChC) داده است. این انیمیشن ۵ ثانیه‌ای با فرمت dotLottie از نشانی داراییِ منتشرشدهٔ سازنده خوانده می‌شود و صفحهٔ منبع، استفادهٔ آن را تحت **Lottie Simple License** مجاز اعلام می‌کند.
